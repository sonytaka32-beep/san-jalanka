# Tulia Jadwal

Aplikasi notepad dengan fitur jadwal dan notifikasi, mirip Google Notes.

## Fitur
- Membuat dan mengelola catatan
- Fitur jadwal (schedule)
- Search catatan
- Tampilan modern dan responsif
- Support offline (Service Worker)
- Installable sebagai PWA

## Build APK Debug
Build otomatis via GitHub Actions. Setiap push ke branch main akan meng-build APK debug Android.

## Tech Stack
- HTML5, CSS3, JavaScript
- PWA (Progressive Web App)
- Cordova (untuk build APK)
- GitHub Actions (CI/CD)
